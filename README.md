# Dashboard_Rapport_activites
L’objectif est de transformer des données brutes en informations exploitables grâce à un processus complet de préparation, de modélisation et de visualisation des données. Le projet s’appuie sur la construction d’un modèle de données en étoile, la création de mesures avec le langage DAX et le développement de tableaux de bord interactifs.
